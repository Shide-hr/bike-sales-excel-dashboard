# 🚲 Bike Sales Excel Dashboard

## Project Overview
This project is an interactive Bike Sales Dashboard created in Microsoft Excel.

The goal of the project is to analyze customer data and explore factors associated with bike purchases, including income, age, gender, commute distance, education, and marital status.

## Dashboard

The dashboard includes:

- Average income by gender and bike purchase status
- Bike purchases across different customer age groups
- Bike purchases based on commute distance
- Interactive filters for marital status, gender, and education

## Excel Skills Used

- Data Cleaning
- PivotTables
- PivotCharts
- Slicers
- Data Visualization
- Dashboard Design

## Files

- `bike_sales_dashboard.xlsx` – Final Excel workbook containing the analysis and interactive dashboard
- `bike_sales_dataset.xlsx` – Original dataset used for the project
